# Linguaggio-controllato-in-italiano-basato-su-CNL2ASP-e-CNLWizard
Strumento per la traduzione automatica di frasi scritte in italiano controllato in programmi ASP. L’obiettivo è quello di superare il limite linguistico dello strumento CNL2ASP, che supporta esclusivamente l’inglese, permettendo così anche agli utenti italiani di produrre programmi ASP in maniera più semplice e diretta.
